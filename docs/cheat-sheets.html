Before you change a setting

  1. Reproduce. Same place, same camera, a development build on the target hardware.
  2. Find the lane. Game thread, render thread or GPU: only the longest one matters.
  3. Capture at two levels. Compare pass by pass, in milliseconds, not frames per second.
  4. Change one thing. Then measure again, in the same place.

From 11.5, with each row's chapter linked. Dots are a rough guide, not measurements; ray-traced reflections and GI cost far more than their rows suggest (8.6).
